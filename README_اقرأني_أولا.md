# نظام جار الخليج المتكامل — البوابة الرئيسية v1.0

## ما الذي تحتويه الحزمة؟

هذه نسخة مجمّعة من **18 صفحة HTML أصلية** مقدمة من شركة جار الخليج للصناعة، داخل بوابة جديدة متجاوبة للكمبيوتر والآيباد والجوال.

- `index.html`: **الصفحة الرئيسية الجديدة**.
- `apps/`: النسخ الأصلية للتطبيقات مع إضافتين محدودتين لكل صفحة: ربط التنقل بالبوابة وملف CSS لتحسين العرض على الشاشات الصغيرة، دون تعديل منطق Firebase أو حقل حفظ البيانات.
- `assets/portal.js` و`assets/portal.css`: قائمة التطبيقات، البحث، المفضلة، العرض المتجاوب، وإعدادات القفل.
- `assets/catalog.js`: تعريف أسماء ومجموعات وروابط التطبيقات.
- `apps/dashboard.html`: مسار توافق يؤدي إلى `dashboard(3).html`، لأن صفحة الإنتاج كانت تستخدم الاسم القديم.
- `catalog.json`: وصف التطبيقات والعلاقات بينها.
- `checksums.json`: بصمات SHA-256 لكل ملف أصلي ونسخته داخل الحزمة.
- `تقرير_الفحص_والدمج.md`: نتائج مراجعة التجميع وحدوده.

## التشغيل على كمبيوتر Windows

1. فك ضغط ملف ZIP **مع الاحتفاظ بكل المجلدات**.
2. افتح مجلد `Jar_Al_Khaleej_Unified_System` في مستكشف الملفات.
3. شغّل `تشغيل_محلي_Windows.bat` إذا كان Python مثبتًا، أو افتح PowerShell داخل المجلد وشغّل:

   ```powershell
   py -m http.server 8000
   ```

4. افتح العنوان `http://localhost:8000` في Chrome أو Edge، مع توفر الإنترنت للوصول إلى Firebase والمكتبات الخارجية.
5. في أول دخول اختر **PIN من 6 إلى 12 رقمًا**، أو **نمطًا من 4 نقاط**، أو **كلمة مرور من 10 أحرف**. بعد الدخول يمكن تغيير الطريقة من «الإعدادات والأمان» مع تأكيد الطريقة الحالية.
6. عند مشاركة التطبيقات بين الموظفين أو فتحها من أجهزة متعددة، انشر **المجلد كاملًا** على استضافة HTTPS مناسبة ثم اضبط صلاحيات Firebase والتوثيق؛ صفحة الدخول الحالية ليست حاجز وصول خادمي.

> **مهم:** لا تعتمد على فتح `index.html` بالنقر المزدوج (`file://`): متصفحات مختلفة تقيد التخزين والتشفير والتصفح بين الملفات في وضع الملفات المحلية. استخدم `localhost` أو HTTPS.

## نظام التنقل

- القائمة الرئيسية تُصنِّف 18 تطبيقًا تحت ست إدارات.
- «فتح التطبيق» يفتح الصفحة الأصلية داخل إطار عرض بنفس الموقع؛ عمليات حفظ Firebase الخاصة بها تعمل وفق الصلاحيات الأصلية.
- روابط طلبات جار الخليج المعروفة تعمل داخل البوابة: إنشاء الطلب، لوحة الإنتاج، طباعة الطلب، لوحة الطلبات.
- يمكنك البحث والتصفية حسب الإدارة ووضع نجمة ⭐ للتطبيقات كثيرة الاستخدام.
- تنتقل بين التطبيقات باستخدام القائمة الجانبية أو الرجوع إلى «الرئيسية» دون نقل ملفات التطبيق من مكانها.
- التطبيقات ذات شاشات دخول خاصة بها **ما زالت تطلب تلك البيانات**؛ لا يتم تجاوز مصادقتها تلقائيًا.

## الأمان — مهم قبل التشغيل الفعلي

- وسيلة PIN/النمط/كلمة المرور هي **قفل محلي لواجهة البوابة فقط** وليس نظام حسابات موظفين ولا وسيلة لتأمين الملفات المنشورة أو قواعد البيانات.
- يتم تخزين *مشتق مجزأ* من وسيلة الدخول باستخدام PBKDF2/SHA-256 وملح عشوائي، وليس الكلمة نفسها نصًا؛ لكن كلمات المرور القصيرة والـPIN تظل قابلة للتخمين إذا حصل المهاجم على نسخة من بيانات المتصفح.
- كل جهاز ومتصفح يحتاج إعداد وسيلة الدخول الخاصة به؛ ليس هناك حساب مركزي أو مزامنة لوسيلة القفل بين الأجهزة.
- يمكن لمن لديه وصول مباشر لعنوان `apps/*.html` أو للملفات على الخادم محاولة تجاوز القفل. **الحماية الحقيقية يجب فرضها عبر خادم/مزوّد هوية وFirebase Security Rules لكل مشروع**، وليس عبر إخفاء الأزرار أو تحويل الروابط.
- توجد **تسعة مشاريع Firebase** في التطبيقات. الحساب على أحد المشاريع لا يمنح تلقائيًا الوصول إلى الآخر.
- لا تُغيّر قواعد Firestore الحالية أو مشاريع Firebase قبل مراجعة الصلاحيات وتوافق البرامج، ولا تستخدم إعدادات `allow read, write: if true` في الإنتاج.
- مستخدم الصيانة لديه واجهة دخول إضافية؛ ويظل تمكين Authentication وإعداد قواعده مسؤولية المسؤول عن Firebase.
- لم يتم الاتصال بقواعد البيانات الحقيقية ولم تُعدّل أي سجلات أثناء إعداد هذه الحزمة.

## ملاحظات على العرض والطباعة

- أضيفت تحسينات صغيرة للشاشات الأقل من 900 و560 بكسل، مع الحفاظ على CSS الطباعة الأصلي (`@media print`).
- الجداول الكبيرة تعرض تمريرًا أفقيًا في الجوال بدلاً من تقليص معلوماتها أو حذف الأعمدة.
- بعض صفحات الخزانات والتقارير الهندسية مصممة للطباعة على A3/A4 ويستحسن استخدامها بالعرض على آيباد أو كمبيوتر.
- قد تختلف بعض التصاميم القديمة عن هوية البوابة؛ إعادة بنائها بالكامل يتطلب تعديل كل تطبيق على حدة ومراجعة وظائفه بعد كل تعديل.
- التطبيقات تعتمد على مكتبات CSS/JavaScript عامة؛ تتطلب اتصالًا بالإنترنت وقد لا تعمل مع حظر CDN.

## ملف لم يتم دمجه

`دليل مفوتر سداد SADAD.lnk` هو **اختصار برنامج Windows** يشير إلى بيئة Chrome على جهاز معين، وليس صفحة HTML أو ملف الدليل نفسه. لم يُضمَّن داخل الموقع لتجنب المسارات المحلية والروابط غير القابلة للنقل. للدمج، يلزم ملف PDF أو عنوان URL الفعلي للدليل.

## رفع نسخة جديدة من أحد البرامج مستقبلاً

يمكن استبدال ملف HTML داخل `apps/` **بنفس الاسم**، لكن يجب نقل وسمَي `assets/legacy-mobile.css` و`assets/app-bridge.js` من النسخة السابقة إذا لم يكونا ضمن الملف الجديد، وإعادة اختبار وظائفه. لم تُدمَج مشاريع Firebase في قاعدة واحدة.
